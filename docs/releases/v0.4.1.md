随译 v0.4.1 让快速模式按当前输入情况自动打开翻译框。

- 在支持的可编辑输入框选中文字后，按现有快捷键直接翻译并替换选区。
- 没有选中文字时，同一快捷键打开翻译框供手动输入；已捕获的输入位置保留，确认后仍可填回原光标位置。
- 没有可用输入框或无法读取选区时，打开翻译框供手动输入、复制，并显示无法绑定输入位置的原因。
- 保留托盘和设置中的“快速模式”开关；关闭后恢复普通模式，始终打开翻译框预览。没有增加快捷键，也不改变已有模式和快捷键偏好。
- 捕获阶段取消后不再打开浮窗；直接替换时仍检查焦点和选区，翻译或替换失败时显示短暂提示。
- 更新模式开关的中英文提示、README、使用说明和技术文档。

51 项前端和 Rust 自动检查、Clippy 严格检查及开发构建通过。Windows 桌面使用隔离配置和本地假接口验证直接替换、无选区浮窗及回填、无输入框复制浮窗，以及关闭快速模式后的选区预览。正式安装包和便携包由 GitHub Actions 构建，发布流程验证隔离安装、覆盖升级与卸载。

已有安装版可从托盘“检查更新”升级，配置和加密密钥保留。

Suiyi v0.4.1 opens the translation window automatically when Quick Mode has no selection to replace.

- Select text in a supported editable field and use your existing shortcut to translate and replace it directly.
- With no selected text, the same shortcut opens the translation window for manual input. The captured input position stays available for insertion after confirmation.
- With no usable input field or readable selection, the translation window provides manual input and copying, with feedback when an insertion target cannot be bound.
- Keeps the Quick Mode switch in Settings and the tray. Turn it off to always preview translations. No extra shortcut or changes to saved mode and shortcut preferences.
- Canceling during capture no longer opens the window. Direct replacement still checks focus and selection; translation or insertion failures show a brief notice.
- Updates the switch hints in both interface languages, READMEs, user guide, and technical documentation.

All 51 frontend and Rust automated checks, strict Clippy checks, and the development build pass. Windows desktop checks with an isolated profile and a local mock API cover direct replacement, popup insertion without a selection, copying without an input field, and selection preview with Quick Mode off. GitHub Actions builds the installer and portable ZIP and checks isolated installation, in-place upgrades, and uninstallation.

Update from the tray menu; settings and encrypted keys are preserved.
