随译 v0.5.0 始终启用智能互译，用语言组合替代固定目标语言。

- 设置“主要语言”和“常用外语”：主要语言译为常用外语，其他语言译为主要语言。例如日语＋英语组合中，日语译为英语，英语、中文、法语等均译为日语。
- 移除固定目标语言入口，不增加智能互译开关。12 种语言均可作为组合成员；选择另一项已使用的语言时自动交换两项。
- 主要语言初始值参考 Windows 显示语言，包括日语、简繁中文等；不支持的系统语言回退英语。常用外语默认英语，主要语言为英语时默认简体中文，两项均可修改。
- 托盘和浮窗显示当前组合。托盘可调整两项并保存，设置页同步组合，保留未保存的 API、Key 和模型草稿。
- 模型在同一次请求中识别整段主要语言并翻译；多行统一使用同一目标并保留空行。快速替换和普通浮窗共用规则。缓存同时区分两项语言，组合改变后使旧译文失效。
- 旧固定目标语言迁移为常用外语，与主要语言相同时调整为默认外语；接口、加密密钥、模式、快捷键及主题偏好保留。保存配置使用版本 3。

升级后翻译方向会按上述规则自动选择，原固定目标行为不再提供。语言识别和译文质量取决于所选模型，短词和混排可能存在歧义。

58 项前端和 Rust 自动检查、Clippy 严格检查及开发构建通过。正式安装包与便携包由 GitHub Actions 构建，并验证隔离安装、覆盖升级和卸载。已有安装版可从托盘“检查更新”升级。

Suiyi v0.5.0 enables smart translation for every request and replaces the fixed target with a language pair.

- Choose your primary and another language. Primary-language text goes to the other language; all other languages go to your primary language. With Japanese + English, Japanese goes to English, while English, Chinese, French, and other source languages go to Japanese.
- Removes the fixed-target entry without adding a smart-translation switch. Both selectors support all 12 languages. Selecting the other member swaps the pair.
- The initial primary language follows the Windows display language, with English as the fallback for unsupported languages. The other language defaults to English, or Simplified Chinese when the primary language is English. Both remain editable.
- The tray and popup show the pair. Edit both languages from the tray and save together. Settings synchronizes the pair while retaining unfinished API endpoint, key, and model edits.
- Detects the predominant source language and translates within one request. All lines share one target and preserve blank lines. Quick Mode and popup translation use the same rules. Cache entries include both languages, and changing either invalidates previous results.
- Migrates the previous target to the other language, adjusting duplicate members to a valid default. API settings, encrypted keys, mode, shortcut, and theme preferences are preserved. Saved configuration uses version 3.

Translation direction now follows these rules; fixed-target translation is no longer available. Source detection and translation quality depend on the configured model, and short or mixed-language text can be ambiguous.

All 58 frontend and Rust automated checks, strict Clippy checks, and the development build pass. GitHub Actions builds the installer and portable ZIP and checks isolated installation, in-place upgrades, and uninstallation. Existing installations can update from the tray menu.
