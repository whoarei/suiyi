随译 v0.6.0 支持翻译网页正文、文档和桌面应用里的只读选区。

- 选中文字后按翻译快捷键（默认 `Ctrl+Alt+T`），浮窗会自动显示译文。点击“复制”或按 `Ctrl+Enter` 可复制译文。
- 开启快速模式时，可验证的编辑选区仍会原位替换。只读选区会打开浮窗。
- 已在 Chrome、Edge 和 WPF 只读文本框中验证。可读范围取决于应用提供的选区信息。

已有安装版可从托盘菜单的“检查更新”升级。

Suiyi v0.6.0 can translate read-only selections in supported web pages, documents, and desktop apps.

- Select text and press your translation shortcut (`Ctrl+Alt+T` by default) to see the translation in the popup. Click Copy or press `Ctrl+Enter` to copy it.
- Quick Mode still replaces verified editable selections in place. Read-only selections open the popup.
- Verified with Chrome, Edge, and a read-only WPF text box. Selection capture depends on what the application exposes.

Existing installations can update from the tray menu.
