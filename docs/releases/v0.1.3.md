随译 v0.1.3 为密钥输入框补上显示与隐藏按钮。

- 点击“小眼睛”切换密钥的明文和遮蔽显示；当前输入为空时，可查看当前 API 地址已保存的密钥。
- 设置窗口失去焦点时自动隐藏明文，关闭时清空输入控件。
- 切换 API 地址时，不会将通过“小眼睛”查看的已保存密钥带到另一个地址。

本版包含 [v0.1.2](https://github.com/whoarei/suiyi/releases/tag/v0.1.2) 的通用接口、模型获取、选区翻译、快速模式、自定义快捷键及新版托盘菜单。

下载 Windows x64 便携包并完整解压，运行 `Suiyi/TranslationFloat.exe`。升级前退出旧版；本机接口配置与密钥会保留。附件提供 SHA-256 校验文件。

本版包含 138 项自动检查，其中 9 项使用隐藏的真实设置控件与虚构密钥验证显示和隐藏行为。
