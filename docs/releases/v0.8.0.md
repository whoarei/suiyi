随译 v0.8.0 首次在 GitHub Release 提供 Android 版。

- Android 1.0.2 支持从其他应用的划词菜单翻译。支持回填的输入框可直接替换选区，只读文字可复制译文。也可分享文字到随译，或在主界面输入和粘贴。
- Android 版适用于 Android 6.0 及以上。首次启动可试用本地演示，也可在设置中配置 OpenAI 兼容的翻译服务。
- 此 APK 使用 GitHub 发布签名。已装过其他签名的测试包或本地构建时，需要先卸载旧版再安装。卸载会清除应用设置。
- Windows 继续提供 x64 安装包和便携包。已有安装版可从托盘菜单检查更新。

---

Suiyi v0.8.0 is the first GitHub Release to include an Android APK.

- Translate selected text in other apps. Replace text in supported editable fields or copy the translation of read-only text. You can also share text to Suiyi or enter it in the main window.
- Android 1.0.2 requires Android 6.0 or later. Try the built-in demo or configure an OpenAI-compatible translation service in Settings.
- If you installed a test or local build signed with another key, uninstall it before installing this release. Uninstalling clears app settings.
- The Windows x64 installer and portable package remain available. Existing users can check for updates from the tray menu.
