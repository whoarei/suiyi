Suiyi v0.3.0 moves to Tauri 2 + Rust, preserving the translation workflow while making downloads much smaller.

- The Windows x64 installer is about **3.7 MiB**, and the portable ZIP is about **2.4 MiB**. The installer is approximately **92.8% smaller** than v0.2.4's 51.2 MiB download and no longer includes the .NET runtime.
- Setup reuses WebView2 when available. If it is missing, setup downloads Microsoft's bootstrapper, verifies its Microsoft digital signature, and installs the runtime. This first-time runtime download requires internet access and is additional to the installer size above.
- Keeps Quick Mode, the translation popup, selection replacement, OpenAI-compatible APIs, model discovery, configurable shortcuts, startup at login, the custom tray menu, all 10 themes, system light/dark mode, and in-app updates.
- Preserves the installation path, API endpoint, model, encrypted keys, and preferences. In-place upgrades remove the old bundled .NET runtime files.
- Updates both READMEs, installation and usage guides, compatibility notes, and the technical design. The WPF design is archived for reference.

39 automated checks pass. Manual verification covers normal and quick replacement, multiline and rich-text web inputs, and password-field protection. Isolated installer checks cover installation, upgrades, uninstallation, and WebView2 detection; the missing-runtime branch uses a test stub without removing the shared runtime. See the [compatibility notes (Chinese)](https://github.com/whoarei/suiyi/blob/v0.3.0/docs/compatibility.md) for scope and limitations.

Existing installations can update from the tray menu or run `suiyi-0.3.0-windows-x64-setup.exe` in place. Portable users need WebView2 already installed.
