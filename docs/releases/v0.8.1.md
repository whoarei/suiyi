随译 Android 1.0.3 加入应用内更新。

- 在设置底部点「检查更新」。发现新版后，随译会从 GitHub 下载并校验 APK，再打开 Android 系统安装界面。
- 从 Android 1.0.2 升级时，请先下载本页的 APK 手动覆盖安装。此后的版本可在应用内更新。
- Windows 继续提供 x64 安装包和便携包。

---

Suiyi for Android 1.0.3 adds in-app updates.

- Tap **Check for updates** at the bottom of Settings. When an update is available, Suiyi downloads and verifies the APK from GitHub, then opens the Android installer.
- To upgrade from Android 1.0.2, download and install the APK from this release. Later updates are available in the app.
- The Windows x64 installer and portable package remain available.
