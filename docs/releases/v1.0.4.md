Starting with `1.0.4`, Suiyi for Windows and Android share a version number and ship in the same GitHub Release.

- The Windows executable, installer, taskbar and tray now use the same translation mark as Android. The icon follows the selected desktop theme.
- Android 1.0.3 users can upgrade from **Settings → Check for updates**.
