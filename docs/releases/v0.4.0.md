随译 v0.4.0 支持从托盘直接切换目标语言。

- 托盘菜单显示当前目标语言，点击进入两列语言列表，12 种语言直接选择，当前项带勾选；选择后立即保存并收起菜单。
- 返回按钮或 Esc 回到主菜单，无需打开设置或再次确认保存。
- 与设置页共用配置并即时同步目标选择，保留设置中正在编辑的 API 地址、Key 和模型等内容；原有接口配置和加密密钥保持不变。
- 切换后使旧译文和缓存失效，后续浮窗翻译与快速替换使用新语言。翻译或回填进行中提示稍后切换，保存失败时保留原选择。
- 按菜单实际尺寸定位，并在尺寸变化时按显示器工作区修正位置。更新中英文 README、使用说明与技术方案。

48 项前端和 Rust 自动检查通过；另验证中英文页面、语言切换、失败恢复、返回操作及设置草稿保留。发布流程验证隔离安装、覆盖升级与卸载。已有安装版可从托盘“检查更新”升级，原有配置和密钥保留。

Suiyi v0.4.0 lets you switch the translation target directly from the tray.

- The tray menu shows the current target. Open the two-column language list and choose from all 12 languages; the active language is checked. A successful selection is saved immediately and closes the menu.
- Use Back or Escape to return to the main menu. No need to open Settings or confirm a separate save.
- Shares the same target setting with Settings and updates its selection immediately, preserving unfinished API endpoint, key, and model edits. Saved API settings and encrypted keys are preserved.
- Invalidates previous translations and cache entries. Subsequent popup translations and Quick Mode use the new target. If translation or insertion is in progress, wait and retry; a failed save keeps the previous selection.
- Positions the menu using its actual size and adjusts it to the monitor work area when resized. Updates both READMEs, the user guide, and technical design.

48 frontend and Rust automated checks pass. Additional verification covers both interface languages, switching and failure recovery, Back/Escape, and preserving Settings drafts. The release workflow checks isolated installation, in-place upgrades, and uninstallation. Update from the tray menu; settings and encrypted keys are preserved.
