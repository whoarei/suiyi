随译 v0.3.2 新增目标语言选择和自动中英文界面，并修复编辑框聚焦时出现两圈边框的问题。

- 设置新增“译为”，提供英语、简体中文、繁体中文、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、意大利语和阿拉伯语，默认英语，原文语言由模型识别。
- 浮窗、快速替换和连接测试共用所选目标语言。保存后保留选择，并清除旧缓存、使旧译文失效；旧配置继续默认使用英语。
- 程序界面自动跟随 Windows 显示语言：中文系统使用中文，其他语言使用英文，覆盖浮窗、设置、托盘菜单、更新页和提示，不增加语言设置或启动参数。更改系统显示语言后重启随译生效，翻译目标不受界面语言影响。
- 原文与译文支持自动文字方向，适配阿拉伯语等从右到左的文字。
- 编辑框聚焦时统一使用单层细边高亮，去掉边框与额外焦点轮廓叠加的效果；普通按钮保留键盘焦点提示。
- 更新中英文 README、使用说明、技术方案及验证记录。

45 项前端和 Rust 自动检查通过，并验证中英文各五类页面、焦点样式及目标语言保存和重启保留。发布流程另验证隔离安装、覆盖升级和卸载。已有安装版可从托盘“检查更新”升级，接口配置、密钥与偏好保留。

Suiyi v0.3.2 adds target language selection and an automatic Chinese/English interface, and fixes the double outline around focused text fields.

- Choose a target language in Settings: English, Simplified Chinese, Traditional Chinese, Japanese, Korean, French, German, Spanish, Portuguese, Russian, Italian, or Arabic. English is the default; the model detects the source language.
- The popup, Quick Mode, and connection test use the selected target. Saving keeps the selection and invalidates previous translations and cache entries. Existing settings default to English.
- The app interface follows the Windows display language: Chinese for Chinese systems, English otherwise. Covers the popup, settings, tray menu, update window, and notices, without an extra setting or launch option. Restart Suiyi after changing the Windows display language. Interface language does not change the translation target.
- Source and result fields detect text direction automatically, including right-to-left Arabic text.
- Focused text fields use a single highlighted border. Ordinary buttons retain keyboard focus indicators.
- Updates both READMEs, the user guide, technical design, and verification notes.

45 frontend and Rust automated checks pass. Verification also covers all five views in both interface languages, focus styles, and saving and reloading the translation target. The release workflow checks isolated installation, in-place upgrades, and uninstallation. Update from the tray menu; API settings, encrypted keys, and preferences are preserved.
