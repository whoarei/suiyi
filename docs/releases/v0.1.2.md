随译 v0.1.2 支持通用翻译接口，以及无需确认、直接替换选中文字的快速模式。

### 新功能

- **通用 OpenAI 兼容接口**：自填 API 地址、Key 和模型，不预设厂商；点击模型右侧下载图标获取列表，也可手动填写模型 ID。
- **选中文字翻译并替换**：选中输入框中的原文，按快捷键翻译，再确认替换，保留前后内容。
- **快速模式**：后台翻译并直接替换，全程不显示翻译浮窗；失败只显示约 3 秒的提示，等待时可再次按快捷键取消。
- **自定义唤出快捷键**：点击设置中的快捷键输入框后直接按键录入，保存后生效，支持恢复默认。

### 界面与体验

- 设置页精简为 API 地址、Key、模型和快捷键四行，保留快速模式、测试、保存及关闭入口。
- 托盘菜单采用圆角白底、浅绿悬停、线条图标和分组；快速模式与开机启动显示为滑动开关。
- 使用新的“译入光标”程序和托盘图标；翻译浮窗继续保持极简布局。
- 成功填入后自动清空原文和译文；翻译或回填失败时不会自动重复粘贴。

### 配置与兼容

- 旧版 DeepSeek 配置与密钥继续加载，保存时自动迁移为通用配置。密钥在本机加密，按 API 地址分别保存。
- 接口使用 OpenAI Chat Completions 格式；模型获取不受支持时仍可手填。“测试”会验证单行和带空行的多行翻译。
- 快速模式默认关闭，可从托盘或设置开启。窗口、焦点或原选区变化时停止替换。
- 选区翻译支持常见可编辑输入框；未提供选区信息的自绘控件仍需使用普通浮窗手动输入原文。

### 下载与升级

下载 Windows x64 便携包并完整解压，运行 `Suiyi/TranslationFloat.exe`，无需另装 .NET。升级前先退出旧版，再替换程序文件；本机接口设置与密钥会保留。默认唤出快捷键为 `Ctrl+Alt+T`，普通模式使用 `Ctrl+Enter` 确认回填。

构建包含 129 项自动检查。附件中的 `.sha256` 文件用于校验便携包完整性。
