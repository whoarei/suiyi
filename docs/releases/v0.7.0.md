随译 v0.7.0 更新了翻译浮窗和其他窗口的界面。

- 只读选区默认显示译文，点击“查看原文”可展开对照。
- 手动输入和替换共用紧凑布局，原文和译文用细线分隔。浮窗随内容调整大小。
- 复制使用双页图标，成功后短暂显示对勾。仅复制模式下也可按 `Ctrl+Enter`。
- 设置、托盘菜单、语言与主题面板、更新页和提示窗统一了间距、圆角和按钮样式。

已有安装版可从托盘菜单的“检查更新”升级。

Suiyi v0.7.0 introduces a more compact translation popup and a consistent look across the app.

- Read-only selections show the translation first. Click **Show source** to see the original.
- Manual input and replacement use a compact layout with a single divider. The popup resizes to fit its content.
- The copy icon briefly changes to a check mark after a successful copy. In copy mode, `Ctrl+Enter` also copies the translation.
- Settings, the tray menu, language and theme panels, updates, and notices share the same spacing, corners, and button styles.

Existing installations can update from the tray menu.
