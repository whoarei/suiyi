此版本未发布：CI 安装测试脚本的 SDK 路径问题导致发布流程中止。请使用 [v0.2.2](https://github.com/whoarei/suiyi/releases/tag/v0.2.2)。以下为原计划。

随译 v0.2.1 增加 Windows 安装包，并支持在程序中下载和安装更新。

- 默认安装到当前用户的 `%LOCALAPPDATA%\Programs\Suiyi`，提供开始菜单入口和卸载入口，无需管理员权限。
- 在托盘菜单“检查更新”中发现新版后，可“下载并安装”，显示下载进度，并校验安装包大小及 SHA-256。
- 下载或校验失败可重试，关闭窗口可取消下载；当前操作未结束或设置窗口仍打开时，先保留下载，等待点击“安装更新”。
- 安装器会正常关闭随译，覆盖升级并重新启动；接口配置、加密密钥及偏好继续保留。卸载也保留用户配置。
- 继续提供 Windows x64 便携包和两类附件的 SHA-256 文件。

首次从 v0.2.0 及更早的便携版迁移，请下载 `suiyi-0.2.1-windows-x64-setup.exe`，退出旧版后安装。后续带有效安装包摘要的正式版可在程序内完成下载和安装；没有可自动校验安装包的旧 Release 仍使用发布页面下载入口。

173 项自动检查覆盖翻译、回填、设置、更新查询及下载校验；安装器另验证首次安装、关闭持锁进程后升级、卸载保留外部配置和非托管文件。
