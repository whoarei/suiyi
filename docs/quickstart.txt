运行 TranslationFloat.exe，程序会驻留托盘。
右键托盘菜单中的“主题”可选蓝、青、绿、青柠绿、黄、橙、粉、洋红、紫、黑共十种配色，默认橙色并记住选择。
浅色与深色自动跟随 Windows 的应用颜色模式，系统切换后立即同步；更换颜色不清空正在编辑的内容。
窗口、任务栏及托盘图标也跟随主题；默认程序图标为橙色。
推荐使用 setup.exe 安装包，默认安装到当前用户的 %LOCALAPPDATA%\Programs\Suiyi，无需管理员权限。
右键托盘图标选择“检查更新”，有新版安装包时可“下载并安装”，下载后校验并覆盖升级，完成后自动重启。
安装、升级及卸载均保留本机接口配置与加密密钥；关闭窗口可取消下载，失败可重试。
当前操作或设置未结束时，请完成操作并关闭设置，再点击“安装更新”。
v0.2.0 及更早版本需要先手动安装一次新版。便携版使用程序内安装更新后，后续从开始菜单运行安装版。
便携包仍可完整解压运行；缺少有效安装包摘要的旧 Release 使用发布页面下载入口。
首次运行默认开启“开机启动”，右键托盘图标可取消勾选，关闭选择会一直保留。
登录 Windows 后仅驻留托盘；便携目录移动后请手动运行一次以更新启动路径。
删除程序前可先取消“开机启动”。此设置不需要管理员权限。
首次使用：从托盘菜单打开“设置”，填写 OpenAI 兼容 API 地址、Key 和模型。
智能互译始终启用：主要语言译为常用外语，其他语言译为主要语言。
设置中选择“主要语言”和“常用外语”，支持原有 12 种语言；例如日语＋英语组合会把日语译为英语，其他语言译为日语。
主要语言默认参考 Windows 显示语言，常用外语默认英语；主要语言为英语时，常用外语默认简体中文，两项均可修改。
托盘菜单显示当前语言组合，点击“语言组合”调整两项并保存；返回或 Esc 放弃未保存的组合并回到主菜单。
旧目标语言迁移为常用外语；若与主要语言相同则调整为默认外语。已有接口、加密密钥、模式和快捷键偏好保留。
界面中英文自动跟随 Windows 显示语言，无需手动配置，与已保存的语言组合互相独立。更改系统显示语言后重启随译生效。
不预设厂商或模型。点击模型右侧下载图标（获取模型）查询列表，也可直接手填模型 ID。
点击“测试”验证单行和多行翻译，通过后保存。无鉴权的本地接口可留空 Key。
API 地址填根路径，例如 https://example.com/v1，也可粘贴完整 /chat/completions 地址。
获取模型失败仍可手填；列表中的模型不一定支持聊天翻译，以测试结果为准。
密钥使用当前 Windows 用户加密保存在本机，不包含在运行包中。
密钥按 API 地址分别保存，同地址留空保留原 Key；换地址不自动携带原 Key。
点击密钥框右侧小眼睛可切换显示/隐藏，也可查看当前地址已保存的 Key。
设置失去焦点时自动隐藏，关闭时清空输入；换地址时清空通过小眼睛加载的已保存 Key。
旧版 DeepSeek 地址、模型和密钥会继续加载，保存时迁移为通用配置。

在准备填写的输入框中放好光标，按 Ctrl+Alt+T 唤出。
在上方输入文字，停顿约 450 毫秒后自动请求翻译。
下方显示按语言组合生成的译文，完成后可以手动编辑。
按 Ctrl+Enter 或点击“填入”，将有效译文粘贴到原输入位置。
也可先选中输入框中的已有文字，再按 Ctrl+Alt+T，自动读取选中文字并翻译。
此时主按钮显示“替换”；Ctrl+Enter 只替换原选区，前后文字保留。
原选区或焦点变化时停止替换，译文保留在剪贴板。单个选区上限为 2000 个 UTF-16 代码单元。
未提供选区信息的自绘控件仍需手动将原文放入浮窗，不能保证任意输入框自动读取。
网页正文和只读选区默认显示译文，点击“查看原文”可展开对照。
点击复制图标可复制译文，成功后图标短暂显示对勾。没有回填目标时，Ctrl+Enter 也会复制。
右键托盘图标或在设置页开启“快速模式”，在支持的输入框选中文字后按唤出快捷键，后台翻译并直接替换。只读选区仍打开翻译框。
快速模式直接替换时不显示翻译浮窗，无需 Ctrl+Enter；翻译或替换失败时只显示约 3 秒提示，不抢焦点。
没有选中文字时，同一快捷键打开翻译框供手动输入；有可用输入位置时确认后可填回，没有可用输入框时可复制译文。
无法读取选区时也会打开翻译框，仍需手动输入。无需切换模式，也不增加快捷键。
翻译等待时再按一次唤出快捷键可取消；切换窗口或改变选区会停止替换。
快速模式首次默认关闭，后续记住选择；关闭后恢复普通模式，每次按快捷键都打开翻译框预览并手动确认。
点击快捷键输入框后直接按组合键：Ctrl 或 Alt 配合字母、数字、F1–F12，可加 Shift。
点击“保存”后立即生效；占用冲突时提示更换。↺ 恢复 Ctrl+Alt+T。
右上角 × 和 Esc 都会放弃未保存修改并关闭设置；从托盘打开设置不会显示空白浮窗。
翻译进度显示在译文区域，错误与重试只在需要时显示；目标应用名旁的按钮可悬停查看说明。
程序只执行粘贴。请在目标软件中检查文字，自行决定是否发送或提交。
成功填入后自动清空浮窗原文和译文，下次从空白开始；译文仍保留在剪贴板。
仅复制、取消、回填失败或结果不确定时，草稿继续保留。
Esc 收起并保留草稿；输入法选词期间的 Esc 先取消选词。
下一次选区唤出使用新选中文字；来自选区的草稿在无选区唤出时清空，避免误追加。
退出程序后不保留草稿。托盘菜单可打开复制模式、设置或退出。

新一轮翻译进行中，旧译文不能复制或回填。
多行原文会使用行结构校验；不完整译文需要重试，不会回填半句。
回填会把译文留在剪贴板，并按原输入框当前选区的规则粘贴。
原生编辑框的选区读取会执行 Ctrl+C，可能将选中文字留在剪贴板，不恢复旧剪贴板内容。
回填不再限制应用名单。已识别的密码、只读及不可用控件禁止回填。
部分自绘应用不能区分具体输入区域，请先放好光标，再主动唤出。
辅助识别不可用时不能保证检测所有自绘密码框；焦点或权限受限时请手动粘贴。

已验证：Windows 11 x64，WPF 编辑框、Edge 网页多行及富文本输入框。
