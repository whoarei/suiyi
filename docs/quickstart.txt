随译 DeepSeek 翻译浮窗

运行 TranslationFloat.exe，程序会驻留托盘。
首次运行默认开启“开机启动”，右键托盘图标可取消勾选，关闭选择会一直保留。
登录 Windows 后仅驻留托盘；便携目录移动后请手动运行一次以更新启动路径。
删除程序前可先取消“开机启动”。此设置不需要管理员权限。
首次使用：从托盘菜单打开“设置”，填写自己的 DeepSeek API Key。
默认模型为 deepseek-flash；点击“测试连接”后保存。
密钥使用当前 Windows 用户加密保存在本机，不包含在运行包中。

在准备填写的输入框中放好光标，按 Ctrl+Alt+T 唤出。
在上方输入中文，停顿约 450 毫秒后自动请求翻译。
下方显示英语译文，完成后可以手动编辑。
按 Ctrl+Enter 或点击“填入”，将有效译文粘贴到原输入位置。
也可先选中输入框中的已有文字，再按 Ctrl+Alt+T，自动读取选中文字并翻译。
此时主按钮显示“替换”；Ctrl+Enter 只替换原选区，前后文字保留。
原选区或焦点变化时停止替换，译文保留在剪贴板。单个选区上限为 2000 个 UTF-16 代码单元。
未提供选区信息的自绘控件仍需手动将原文放入浮窗，不能保证任意输入框自动读取。
从托盘打开时主按钮为“复制”，Ctrl+Enter 也会复制。绑定目标时的小复制图标可单独复制。
翻译进度显示在译文区域，错误与重试只在需要时显示；目标应用名旁的按钮可悬停查看说明。
程序只执行粘贴。请在目标软件中检查文字，自行决定是否发送或提交。
成功填入后自动清空浮窗原文和译文，下次从空白开始；译文仍保留在剪贴板。
仅复制、取消、回填失败或结果不确定时，草稿继续保留。
Esc 收起并保留草稿；输入法选词期间的 Esc 先取消选词。
下一次选区唤出使用新选中文字；来自选区的草稿在无选区唤出时清空，避免误追加。
退出程序后不保留草稿。托盘菜单可打开复制模式、设置或退出。

新一轮翻译进行中，旧译文不能复制或回填。
多行原文会使用行结构校验；不完整译文需要重试，不会回填半句。
回填会把译文留在剪贴板，并按原输入框当前选区的规则粘贴。
原生编辑框的选区读取会执行 Ctrl+C，可能将选中文字留在剪贴板，不恢复旧剪贴板内容。
回填不再限制应用名单。已识别的密码、只读及不可用控件禁止回填。
部分自绘应用不能区分具体输入区域，请先放好光标，再主动唤出。
辅助识别不可用时不能保证检测所有自绘密码框；焦点或权限受限时请手动粘贴。

已验证：Windows 11 x64，WPF 编辑框、Edge 网页多行及富文本输入框。
此前完整翻译联调：微信 4.2.0.13 文件传输助手。其他应用需逐步验证。
此目录包含 .NET 运行时，所有文件需要一起保留。
设置目录：%LOCALAPPDATA%\TranslationFloat\
诊断日志 m0.log 不记录原文、译文、密钥或聊天内容。
